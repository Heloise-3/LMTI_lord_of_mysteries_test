# 诡秘之主 · 序列人格测试 (LMTI)

> 在灰雾之中，找到属于你灵魂深处的那一条途径。

一个基于网络小说《诡秘之主》二十二条神秘途径设定的人格测试网页。
通过 48 道情境题，量出你与每一条途径的契合度，并把你定位到具体的**序列号 + 序列名**。

> 例：测得契合度 56% → **序列三 · 古代学者**（愚者途径）

## ✨ 玩法亮点

- **22 条途径全收录**：愚者、太阳、月亮、错误、不公、渔夫、灰烬之神…… 每一条都按原著定位精心设计权重
- **48 道四象限情境题**：覆盖行动、秩序、共情、破局四个维度，凭直觉作答即可
- **精确到序列号**：不仅告诉你属于哪条途径，还会根据契合度判定你处于该途径的**序列 0–9** 中的哪一级，并给出该等级专属称号
- **深度人格解读**：性格定位、核心特质、你的优势、你的盲区、契合途径、互补途径
- **Top 5 灵魂亲缘**：进度条形式展示你最契合的前 5 条途径
- **可下载分享图**：1080×1620 PNG 海报，自动套用对应途径配色，一键保存分享到朋友圈/微博/小红书
- **键盘快捷操作**：按 `1/2/3/4` 或 `A/B/C/D` 选答，`←/→` 翻题

## 🙋 常见问题

**Q：测试结果准确吗？**
A：本测试是结合原著途径设定 + 心理量表思路设计的同人作品，仅供娱乐与自我探索，**不是专业心理评估工具**。

**Q：会保存我的答题数据吗？**
A：不会。整站为纯静态前端，没有后端服务器，你的所有答案只在自己浏览器里计算，关闭页面即清空。

**Q：可以重新测试吗？**
A：可以，结果页底部点"再走一遍灰雾"即可重新开始。

**Q：手机能玩吗？**
A：完全没问题，已做响应式适配。
