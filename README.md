# 诡秘之主 · 序列人格测试

一个零依赖、纯静态的网页人格测试。基于网络小说《诡秘之主》的 22 条途径设计 48 道题，
通过加权评分把测试者匹配到最契合的途径，并定位到该途径中具体的"序列号 + 序列名"。

> 例：测得契合度 56% → 序列三 · 古代学者（愚者途径）。

## 在线体验

部署到 GitHub Pages 后，访问：
`https://<你的GitHub用户名>.github.io/<仓库名>/`

## 功能特性

- **48 道单选题**：四象限主题覆盖（行动/秩序/共情/破局），权重已系统校准
- **22 条途径全收录**：每条途径配 10 个序列名（序列 9 → 序列 0）
- **序列等级系统**：根据契合度自动判定 0–9 级，并展示该途径专属称号
- **结果分析**：性格定位、核心特质、优势/挑战、契合 / 互补途径
- **Top 5 倾向条**：进度条形式展示前 5 条倾向途径
- **可下载分享图**：1080×1620 PNG 海报，自动套用对应途径配色
- **键盘快捷键**：`1/2/3/4` 或 `A/B/C/D` 选答，`←/→` 翻题，`Backspace` 重答上一题
- **响应式布局**：桌面 / 平板 / 手机自适应

## 本地运行

零构建工具，零依赖。任意一种方式即可：

```bash
# 方式 1：直接打开
# 双击 index.html

# 方式 2：用 Python 起一个本地服务器
python -m http.server 8080
# 访问 http://localhost:8080

# 方式 3：用 Node 起一个本地服务器
npx serve .
```

## 部署到 GitHub Pages

1. 将本仓库推送到 GitHub
2. 进入仓库 `Settings` → `Pages`
3. `Source` 选择 `Deploy from a branch`
4. `Branch` 选择 `main` / `(root)` → 保存
5. 等 1–2 分钟，刷新该页面即可看到 GitHub Pages 给的公网网址
